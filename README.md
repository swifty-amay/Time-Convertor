# Time-Convertor
Time Convertor is a SwiftUI iOS app that is built to convert  time from one format to another.

## Description
I build this app while I was on my SwiftUI journey. Although it do not cover much things but yes it covers some of the important SwiftUI aspects like:-
- Picker View with Segmented style
- Displaying numbers in a Text View
- How to handle @Focused state with Text Fields
- And most importantly how to use Forms and Sections
All these things somewhere cover the fundamentals of UI which helps in developing a solid foundation to begin with SwiftUi and so the project.

Building this project was a lot of fun.
